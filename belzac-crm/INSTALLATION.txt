QUICK START (Ubuntu 20.04/22.04)
=================================

1. RUN DEPLOYMENT SCRIPT (Automated - Recommended)
   -------------------------------------------
   
   sudo chmod +x deploy-full-stack.sh
   sudo ./deploy-full-stack.sh
   
   The script will:
   - Install LAMP stack
   - Create database
   - Setup application
   - Configure Apache
   - Set permissions
   
   Duration: ~10 minutes

2. CONFIGURE APPLICATION
   ---------------------
   
   a) Database credentials:
      sudo nano /var/www/html/belzac-crm/config/database.php
   
   b) SMTP settings:
      sudo nano /var/www/html/belzac-crm/config/mail.php
   
   c) App settings:
      sudo nano /var/www/html/belzac-crm/config/app.php

3. ACCESS THE APPLICATION
   ----------------------
   
   URL: http://your-server-ip/belzac-crm/public/
   
   Default Login:
   Email: admin@belzac.com
   Password: password
   
   ⚠️ CHANGE PASSWORD IMMEDIATELY!

4. VERIFY INSTALLATION
   -------------------
   
   - Can login? ✓
   - Dashboard loads? ✓
   - Can create contact? ✓
   - Can create campaign? ✓

MANUAL INSTALLATION
===================

If you prefer manual setup:

Step 1: Install LAMP
--------------------
sudo apt update
sudo apt install apache2 mysql-server php libapache2-mod-php php-mysql -y

Step 2: Create Database
----------------------
sudo mysql
CREATE DATABASE belzac_crm;
CREATE USER 'belzac_user'@'localhost' IDENTIFIED BY 'SecurePass123!';
GRANT ALL ON belzac_crm.* TO 'belzac_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;

Step 3: Import Schema
--------------------
mysql -u belzac_user -p belzac_crm < database_schema.sql

Step 4: Upload Files
-------------------
sudo mkdir -p /var/www/html/belzac-crm
sudo cp -r * /var/www/html/belzac-crm/

Step 5: Permissions
------------------
sudo chown -R www-data:www-data /var/www/html/belzac-crm
sudo chmod -R 755 /var/www/html/belzac-crm
sudo chmod -R 775 /var/www/html/belzac-crm/storage

Step 6: Apache Config
--------------------
sudo a2enmod rewrite
sudo systemctl restart apache2

TROUBLESHOOTING
===============

Cannot connect to MySQL:
- sudo systemctl start mysql
- Check /config/database.php

403 Forbidden:
- Check file permissions
- Check Apache virtual host

API not working:
- Enable mod_rewrite
- Check .htaccess exists
- Verify AllowOverride All
